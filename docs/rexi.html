🐕 Fetch Wrappers

Fetch, boy.
Good fetch.

rexi is fetch() with the rough edges sanded off. Sensible defaults, ergonomic body parsing, friendly errors. For when you need to script HTTP requests instead of declaring them in HTML.

★ Anatomy

fetch(), but you
actually like writing it.

One call. Method shortcuts. Auto JSON. Errors that throw. Use it when you've outgrown fixi attributes and need to script the request.

The JS

// GET → JSON
const users = await rexi("/api/users").json()

// POST with body
const ok = await rexi.post("/save", { name }).text()

// stream the body
for await (const chunk of rexi("/feed").stream())
  console.log(chunk)

★ API

One function.
A few shortcuts.

rexi(url)Default GET request, returns a chainable response
rexi.post(url, body)POST with auto-serialized body (JSON / FormData)
rexi.put / .delete / .patchThe other usual methods
.json()Parse response as JSON, throws on non-2xx
.text()Read response as text
.html()Parse response into a DocumentFragment
.stream()Async-iterable chunks for streaming responses
