★ Anatomy

Add one swap mode
to any fixi request.

Drop paxi on the page and tell fixi to use it. Now your swaps preserve focus, selection, and form state instead of nuking them.

The HTML

<!-- swap with morph instead of innerHTML -->
<form
  fx-action="/validate"
  fx-trigger="input changed delay:300ms"
  fx-target="this"
  fx-swap="paxi">
  <input name="email"/>
  <span class="hint">...</span>
</form>

The Result

As you type, the response morphs into place. Cursor stays put. Focus doesn't blink.

click to morph this output panel.
★ Why morph?

Replace breaks things.
Morphing doesn't.

focusStays on the element you were typing in
selectionHighlight ranges survive a swap
scrollPosition preserved within scrollable regions
animationsCSS transitions run on changed properties
stateForm values, <details> open, <video> playback all kept
cost0.6KB brotli. Cheaper than a single web font weight.
