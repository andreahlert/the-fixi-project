Behavior, right next

Stop hunting through five files for what makes one button work. moxi keeps the script attached to the element it controls.

The HTML

<!-- inline event handler with modifiers -->
<input id="name" placeholder="your name"/>

The Result

★ Attributes & Modifiers

Two attributes,
infinite behaviors.

on-<event>Run JS when an event fires (click, input, submit, ...)
liveJS expression re-evaluated on DOM/form changes
.preventCalls preventDefault() before handler
.stopCalls stopPropagation() before handler
.onceRun handler only once
.debounce-NDebounce handler by N ms
★ Modifier Chain

Read it left to right.
It does exactly that.

Modifiers compose like Unix pipes. Each one is one job, applied in order.

on-click → .prevent → .stop → .debounce-200 → .once → handler()
Locality of behavior. The script is right there, on the element it controls.
— a hyperscript principle, kept
